# JobPilot

粘贴简历，填写一次想找的岗位和城市，点击 **帮我找岗位**。程序会用 AI 提炼经历，扩展相近搜索词，读取实习僧或牛客岗位，再按匹配参考分排序，对前 5 名补充详细分析。

## 怎么运行

Windows 双击 **start.cmd**。页面会自动打开并连接；已经运行时会重新打开原服务。沿用现有 Python 3.12 和 .venv，不需要重装。

1. 首次使用，在左侧底部“连接 DeepSeek”保存服务密钥并测试；已经配置过就不用再填。
2. 粘贴简历全文，也可读取 Word（.docx）或文本文件。**不再手填技能、程度或原文引用。**
3. 填一次岗位意向，例如“Python 后端开发”；城市可填“上海，杭州”。
4. 到岗天数、实习月数选填；留空时从简历提炼，仍不明确则标为待确认。选择网站后直接搜索。
5. 右侧查看 AI 整理的简历原文、分数、时间差距和前几名的详细理由。其余结果可以展开查看。

点击“先用虚构资料体验一下”会把示例填进同一表单，使用本机模拟岗位和规则，不调用 AI、不收费。真实网站会把**简历正文和岗位说明发送给已配置的 DeepSeek**，按账户规则计费。密钥只保存在本机 .env；任务正文、结果和进度保存在本机 data，均不提交 Git。

牛客需要先登录一次专用 Edge；本机此前已经登录。登录失效的处理见 [Demo](docs/demo.md#牛客登录与只读搜索)。不要同时打开同一资料目录的登录窗口与搜索任务。

## 怎样匹配

- **城市是硬条件**：填写城市后，其他城市及地点不明的岗位被排除。明确不同的工作类型、已截止和已下线的岗位也排除。
- **意向采用宽搜索**：AI 提炼相近搜索词；不再要求岗位标题逐字匹配，之后根据工作内容判断职业方向。
- **时间是软条件**：你写 3 天，要求 4、5 天的岗位仍保留，只扣少量分并提醒需要沟通。
- **参考分可以解释**：技能证据 70 分、职业方向 20 分、可用时间 10 分；必需技能权重高于加分项。分数用于本轮排序，**不是录用概率**。
- **前 5 名再次 AI 复核**：指出对应经历、主要缺口、岗位原文中的顾虑和建议确认的问题。经历必须能回到简历原文，不能把缺失技能说成已经掌握。

新页面每次最多尝试读取 100 条详情、每个搜索词最多 20 页。达到上限、重复页或网站验证会明确显示，**不声称已经拿到全站所有岗位**。API 的单次详情上限可设到 200。没有明确截止日期的岗位保留并提示核对，不用发布日期猜测过期。

## 命令与文档

```powershell
cd D:\JobPilot
.\.venv\Scripts\python.exe -m app.server --open-browser
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m scripts.dashboard_smoke
.\.venv\Scripts\python.exe -m app.evaluation.runner
```

当前 271 项测试通过，1 项因缺少专用 PostgreSQL 库跳过。页面回归覆盖自动提炼、单栏输入、评分排序和前五名复核；原 Phase 0/1 CLI 和旧审批 API 保留。早期严格筛选的教学入口行为不变，新页面使用独立的软条件策略。

先读 `resume_service.py` → `ranking_service.py` → `workflow/graph.py`，再看两个网站 Adapter 和 `app/web/`。完整目录、学习路线与面试要点见 [代码导读](docs/file-guide.md)。

本次真实牛客验证使用虚构简历：每周 3 天，上海；读取 5 条，保留 2 条上海岗位，分别要求 4 天和 5 天，均完成评分及详细分析。可在“以前的搜索”查看“排序验收同学”。
