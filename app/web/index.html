第一次使用：怎么添加助手？
  1. 在正常使用的 Edge 中打开 edge://extensions（Chrome 用 chrome://extensions）。
  2. 打开“开发人员模式”，选择“加载解压缩的扩展”，选中 D:\JobPilot\extensions\boss_readonly。
  3. 以前添加过这个助手的，点击它的“重新加载”即可。
  4. 回到本页刷新，点击“连接 BOSS 助手”。在同一个浏览器登录 BOSS，保持助手页打开。

添加一次即可。以后仍在本页填写简历和意向，不需要复制任何连接码。需要登录或验证时会暂停，等你处理。
